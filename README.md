## 📖 Overview

Comprehensive analysis of AI fairness and algorithmic bias across multiple domains including healthcare, criminal justice, hiring systems, and facial recognition. This project examines bias detection, mitigation strategies, and ethical implications of AI systems.

## 🎯 Key Areas

- **Healthcare AI**: Bias in diagnostic algorithms and treatment recommendations
- **Criminal Justice**: COMPAS recidivism prediction and fairness metrics
- **Hiring Systems**: Automated recruitment bias and demographic disparities
- **Facial Recognition**: Accuracy variations across race and gender

## 🛠️ Technologies

- Python, Pandas, NumPy
- Scikit-learn, Fairlearn
- Matplotlib, Seaborn
- Jupyter Notebook
